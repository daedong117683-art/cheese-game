⭐ 2️⃣ 홈 화면/바탕화면에 정식 앱(PWA) 설치 추천

주소창 없이 진짜 스마트폰·PC 어플처럼 전체 화면으로 실행되며 오프라인에서도 작동합니다.

📌 현재 환경에서 바로 홈 화면 앱으로 추가하는 방법:
• 아이폰 / 아이패드 (Safari): 하단 공유 버튼(⬆️) 터치 ➔ [홈 화면에 추가] 선택
• 안드로이드 (Chrome): 우측 상단 메뉴(⋮) 터치 ➔ [앱 설치] 또는 [홈 화면에 추가]
• PC (Chrome / Edge): 주소창 우측 끝의 앱 설치 아이콘(⊕/🖥️) 클릭
🐙 GitHub Pages 자동 배포 & 안드로이드 APK 추출

함께 생성된 cheese_tycoon_app_package.zip 파일에는 GitHub 자동 배포 워크플로(.github/workflows/pages.yml)와 정식 PWA 매니페스트·서비스워커·아이콘이 모두 들어 있습니다.

  1. 내 GitHub 새 저장소(Repository)에 압축 해제한 파일들을 업로드
  2. 저장소 Settings ➔ Pages ➔ Source: GitHub Actions 선택 시 앱 주소 자동 생성!
  3. 생성된 주소를 PWABuilder.com에 넣으면 안드로이드 .apk 설치 파일 즉시 다운로드 가능!
💾 단독 실행 파일(.html) 백업 다운로드

서버 없이 파일 하나로도 언제든 실행할 수 있는 통합 앱 파일입니다.
